# Triatlon: Athletes Diary

Дневник тренировок для спортсменов, занимающихся триатлоном. Приложение помогает вести историю нагрузок, составлять тренировочные планы и отслеживать статистику.

## Возможности

- Добавление тренировок по плаванию, велоспорту, бегу и другим видам активности.
- Сохранение даты, дистанции, продолжительности и заметок.
- Создание и редактирование собственных тренировочных планов.
- Просмотр статистики за неделю, месяц или год.
- Просмотр дневника выполненных тренировок.
- Отправка информации о тренировке через системное меню «Поделиться».
- Разделы с рекомендациями и полезными статьями.
- Русский и английский интерфейс.

## Технологии

- Swift
- SwiftUI
- Core Data
- iOS 17.0+

Все тренировки и планы сохраняются локально на устройстве.

## Запуск

Откройте `TriatlonAthletesDiarySwiftUI.xcodeproj` в Xcode 16 или новее, выберите iPhone Simulator или подключённое устройство и запустите схему `TriatlonAthletesDiarySwiftUI`.
