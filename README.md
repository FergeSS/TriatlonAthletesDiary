# Triatlon Athletes Diary — SwiftUI

Полный Swift + SwiftUI перенос оригинального Objective-C приложения.

## Требования

- Xcode 16 или новее
- iOS 17.0 или новее

Откройте `TriatlonAthletesDiarySwiftUI.xcodeproj`, выберите симулятор iPhone и запустите схему `TriatlonAthletesDiarySwiftUI`.

Проект повторяет структуру экранов, ресурсы, навигацию и поведение исходного приложения. Данные тренировок и планов сохраняются локально в Core Data. Интерфейс поддерживает русский и английский языки с переключением на стартовом экране.
